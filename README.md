# REV III Handbook – GitHub Pages

Denna mapp är färdig att publicera utan buildsteg.

1. Ta bort gamla filer i repots rot, särskilt `src/` och gammal `index.html`.
2. Ladda upp `index.html` från denna ZIP till repots rot.
3. Commit.
4. I GitHub: Settings > Pages > Deploy from a branch > main > /(root).

Sidan använder inga externa JavaScript-bibliotek eller bildanrop. Anteckningar och bokmärken sparas i localStorage och synkas därför inte mellan enheter.
